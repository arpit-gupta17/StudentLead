# StudentLead management app


A React Native application for managing student leads with full CRUD operations and persistent storage.

#Core Features 
1.Adding, Listing, Deleting and Display of the Leads.
2.AsyncStorage for persistent data storage.
3.React navigation with multiple screens.
4.Basic validation for all required fields.

#Additional Features
1.Pull to refresh on leads.
2.Form Reset after submission.
3.Delete confirmation dialog box.
4.Timestamps for lead creation.

#Technologies used
1.React Native - Mobile app framework.
2.React Navigation - Navigation library.
3.AsyncStorage - Data persistent.
4.React Hooks - State and lifecycle management.

#Prerequisites
1.npm packages.
2.React Native development setup.

#Steps
1.Create a new React Native project.
2.Clone the Project.
3.Install Dependencies -
   1.npm install @react-navigation/native @react-navigation/native-stack.
   2.npm install react-native-screens react-native-safe-area-context.
   3.npm install @react-native-async-storage/async-storage. 
4.js files are as below 
  a)App.js - Main application file.
  b)Screens-
   1.LeadListScreen.js(HomeScreen) - All the leads will appear here.
   2.AddLeadScreen.js - To add new leads.
   3.LeadDetailScreen.js - Consists of all the details of the leads.
  c)Index.js.
5.Running the Application.
